# 早八人格定义

>人格基于「可用时间」推断，而非问卷测试。描述要像朋友说话，不要像励志文案。

## 人格总表

| 人格 | 可用时间 | 占比感 | 推荐倾向 | 语气示例 |
|---|---|---|---|---|
| **极限通勤者** | ≤ 5 分钟 | 5% | 外带柜、免排队、可单手食用 | 「4 分钟，连坐下的时间都没有 —— 极限通勤者，出炉直接拿。」 |
| **Deadline 战士** | 6-10 分钟 | 12% | 出餐最快、组合固定、无选配 | 「9 分钟，刚好够。Deadline 战士不需要思考。」 |
| **稳健补给人** | 11-20 分钟 | 26% | 热饮 + 主食、营养均衡 | 「15 分钟，能坐一会儿了。稳健补给人，今天补点热的。」 |
| **悠哉鉴赏家** | 21-30 分钟 | 24% | 品质优先、可选配、堂食 | 「25 分钟，悠哉鉴赏家上线。今天可以挑点想吃的。」 |
| **从容规划者** | > 30 分钟 | 18% | 完整早餐、品质组合 | 「35 分钟，从容规划者。不着急，慢慢选。」 |
| **临阵磨枪型** | 用户已迟到 | 15% | 极简组合、最快出餐 | 「迟到也不慌。临阵磨枪型，走过路过拿就行。」 |

## 推断规则

### 基础推断
按用户**预计到店时间**减去当前时间，得到可用分钟数，对应上表人格。

### 修正因素

| 因素 | 修正 |
|---|---|
| 周五早晨 | 倾向悠哉鉴赏家（心理上更放松） |
| 周一早晨 | 倾向极限通勤者 / Deadline 战士 |
| 下雨 / 降雪 | 时间感知变紧，可选时间按-2 分钟计 |
| 高温 | 倾向稳健补给人（需要补充水分与能量） |
| 用户连续多日同一时段 | 保持稳定，不要天天换人格 |

### 连续性

人格不是每天随机切换的。系统应保持相对稳定 —— 同一人连续多日通勤时段相近时，人格应保持一致或仅微调。只有在用户时间习惯明显改变（如换了通勤路线）时才切换。

这会让「人格」产生连续感和可信度，而不是每天抽一次的娱乐。

## 呈现格式

```
【今日人格】Deadline 战士
【可用时间】9 分钟（预计 8:22 到店）
【推荐】吉士蛋堡 + 中可 ×1
【到手价】¥21.5（已叠早餐券）
【取餐】8:25 出餐，堂食区报取餐码
```

字段顺序固定，便于用户形成阅读习惯。

## 表述红线

不要出现的内容：
- 励志口号（「今天的努力，会在未来发光」）
- 说教（「你不该这样吃早餐」）
- 焦虑营销（「再不吃就来不及了」）
- 与其他品牌的任何比较

可以出现的：
- 具体的时间与地点
- 来自接口的真实价格与营养数据
- 基于用户输入的合理推断，且明确标注是推断

## 用户自定义

用户可以锁定某个人格作为长期偏好（如「我永远是 Deadline 战士」），也可以完全关闭人格展示只看推荐。设置项：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 展示人格描述 | 开 | 关掉后只给推荐，不显示人格 |
| 锁定人格 | 关| 锁定后不随时间推断变化 |
| 人格变化提醒 | 开 | 切换人格时提示一次|
